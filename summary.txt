CS4315 Web-Based Search Engine Project

This application is a Flask-based search engine that provides a single interface for both live web search and local corpus search. In Web mode, it sends user queries to the Brave Search API and returns ranked web results with titles, links, and snippets. In Local mode, it searches a Whoosh index built from the lyrics dataset, using stemming and relevance ranking to return matching songs. The system includes indexing, query parsing across multiple fields, and snippet highlighting to improve result readability. The project is implemented with Flask, Whoosh, and the Brave API, and is configured for cloud deployment including Railway.

Deployed URL(s):
Main URL: https://bigyandhakal.com


Usage:
Open the main URL and enter a query in the search bar.
Select Web mode to search the internet through Brave API.
Select Local mode to search the indexed lyrics dataset.
Open a result title to view the source page (web mode) or song detail page (local mode).
